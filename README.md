# Lilly Content Studio Demo · 礼来创意工作台

礼来项目的本地 React 演示。2026-10-28 版本包含图文和文献的新建上传流程、视频连续对话，以及支持历史管理的工作台。

## 本地启动

在项目目录执行：

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5173，也可双击 `启动Demo.command`。需要 Node.js 20.19+；首次安装依赖需要网络。服务只监听本机，使用固定端口 5173，端口已被占用时需先关闭原进程。

```bash
npm run build
npm run preview
```

`build` 执行 TypeScript 检查和生产构建。`preview` 的地址以终端输出为准。

## 工作台与最近创作

工作台以紧凑欢迎区和三个独立入口开始，分别新建图文上传、视频对话和文献任务。最近创作展示全部已保存的图文和视频项目，支持按名称搜索、类型筛选以及继续编辑；图文和文献的快速输入会带到各自上传页。侧栏历史同样可滚动访问全部记录。

右键作品或点击行尾“···”，选择“删除创作”后出现确认弹窗。确认将作品移入回收站，可恢复原有文稿、图片及视频会话；删除当前打开的项目会回到工作台。删除状态保存在 localStorage，图文“继续上次创作”、视频历史和在途保存均遵守该状态，刷新后不会重新显示已删作品。回收站不提供永久删除，也不会删除电脑原始文件或共享素材库；清除网站数据仍会清空所有本地记录。

## 文献支持

进入文献支持时先显示空白上传页。“达人脚本优化”和“H5 文献支持”均进入对应的新建流程：上传或粘贴内容 → 分步分析加载 → 查看可编辑结果。示例需主动点击载入，不自动展示已有脚本或三张图片；可通过“继续上次文稿”恢复最近一次结果。

脚本支持粘贴或上传 UTF-8 TXT；H5 支持一次上传多张 PNG、JPG、WebP（最多 8 张，单张 20 MB）。示例三图保留已整理的文字，真实上传相同原图时也会通过文件内容比对载入对应文字；其他新图片需逐图补充文字，当前未接入自动 OCR。分析加载约 4.2 秒，可返回上传继续调整；示例加载已有审阅结果，新内容按段落建立待核查文稿，不自动套用示例证据。

结果页以宽幅全文文稿配合段落建议呈现。H5 点击哪张缩略图，就仅显示该图的文字、建议和关联文献；示例三图对应 2 / 4 / 2 段。切换图片保留编辑，引用编号不重排；应用建议、复制和导出均针对当前图片。用户可以逐段应用或一键应用修改，再自行编辑文稿。

修改类型以文字标签和颜色同时区分：红色删除、橙色合规调整、绿色补充、蓝色润色或手动修改。审阅顺序为文案润色、合规审核、引用添加。导出直接使用当前文稿；TXT 用于纯文本编辑，RTF 可在 Word 等文字编辑器继续编辑，标注稿保留颜色和删除线。

正文引用编号、本段参考文献、文献卡片标题及文末书目均可点击，在新标签页打开对应文献网页；DOI 与 PMID 也可直接跳转。RTF 导出的书目保留超链接，TXT 与复制内容保留 URL。H5 第 8 条尚未定位到原文页面，暂提供明确标注的文献检索入口；补齐其他条目的题名与链接不改变其医学证据核查状态。

内置内容来自 `AI Content Creation - POC Files - 20261023.docx`：

- **达人脚本**：宁博士 13 段原始口播，保留编号、时长、原文及逐段支持边界；原始 Word 可下载。
- **H5 文献支持**：三张 H5 原图及其原文区域、原有引用编号和书目。未核实的引用继续标记待核查。

脚本现有证据于 **2026-10-27 实际联网检索并核对**，包含 11 条来源（9 项原始研究、2 份官方文件）和 28 条主张关联。研究包括 Sacks 2009、Leibel 1995、Fothergill 2016、Sumithran 2011、Villareal 2017、Longland 2016、Nedeltcheva 2010、Tasali 2022 及 Peppard 2000。每条来源保留核对层级、位置、日期、适用范围与 DOI/PMID；摘要核对不等同于全文核验。

两份国家卫健委官方 PDF 和 RIS 书目在 `public/literature/references/`，`ning-research-record.json` 保存来源及映射。自定义文字不会自动套用固定案例的医学证据。页面中的建议和颜色是预置内容的审阅演示，不代表真实模型审核或医学审批通过；手工修改后的表达需要重新核对依据。图片输入不含自动 OCR。

## 视频创作

在同一聊天页持续输入提示词，添加参考素材，选择清晰度和时长后提交。结果内联显示，旧结果可编辑提示词、重新提交并继续保留，取消工作流、分镜时间轴及决策与版本页面。

- 清晰度：**360p、720p、1080p**。
- 时长：点击时长按钮展开滑杆，可在 **5–15 秒**之间按每秒一档选择（5、6、7……15 秒）。
- 全能参考：支持上传参考素材并随每次请求保存；原 Word 的三张参考图可直接用于演示。
- 历次请求保留各自提示词、参考素材与生成参数，视频支持播放和下载。

原 Word 的视频段落写明「请基于下述三张图，生成一个视频10-15秒」。三张图分别是肥胖诊疗路径主题封面、2025 世界肥胖地图数据页、手机指南探索页，保存于 `public/assets/video-references/poc-reference-{1,2,3}.png`。本次界面时长采用用户最新指定的 5–15 秒整数范围。

点击「视频创作」或新建视频时打开空白输入页，不自动填入提示词或参考素材；已有视频可从「最近创作」恢复。清晰度和时长初始为 1080p、10s，只有主动点击右下角「载入演示」才会填入三张参考图和 10 秒演示提示词，并设置同一套参数。发送后先展示约 4.4 秒的任务分析进度，再在消息内确认「动效节奏」和「内容重点」两个问题；两项都选好后继续准备约 5.2 秒，展示用户提供的成品。回答和进行中的阶段也会保存，刷新可以恢复。完全匹配旧 8 秒演示预设的草稿及再次生成输入会自动升级，自定义输入和已完成历史结果保留。

成品使用用户提供的 `礼来视频-1080P清晰增强版.mp4`，原样保存于 `public/assets/videos/client-demo-final.mp4`（海报 `client-demo-final-poster.jpg` 从第 1.8 秒画面提取），实际为 10.10 秒、1080×1080、30fps、H.264 与 AAC 双声道音轨。播放器和下载使用同一份完整成片，URL 带内容版本号以更新旧缓存。此前 33 份三图淡入淡出样片仍保留，供旧对话结果读取。

**当前未接入视频生成模型。** 分析与生成进度为本地模拟，选项、提示词、素材和参数会随每轮保存，但不会据此重新渲染成片；每个新请求均播放上述预置成品，并显示真实规格。界面仍支持 5–15 秒和三档清晰度选择。原大会两版视频和旧参考图动效继续兼容历史记录。

## 图文创作与素材

图文入口默认打开空白新建页，按“上传内容 → 分析与编排 → 查看结果”完成创作。支持粘贴正文、导入 UTF-8 TXT 和上传 PNG、JPG、WebP 图片；正文最多 40,000 字、40 段，图片最多 8 张、每张 20 MB。可单独提供正文或图片；创作需求单独记录，不混入正文。“使用礼医示例”由用户主动选择，载入五个主题文案和素材库中已导入的对应图片。

提交后展示约 4.5 秒的分阶段进度，可取消返回并保留输入。结果页支持逐章节修改标题、正文及搭配图片，即时查看连续长图文或系列图文，并导出 TXT 文稿或嵌入图片的独立 HTML。“新建图文”开始空白任务，“调整输入”可基于原始输入重新编排，已保存作品仍能从最近创作恢复。

**当前为本地图文编排演示，未接入图像生成或 OCR。** 段落按空行划分，图片按上传顺序搭配，原始文案不会被自动改写。旧版五张 4:3 海报的创意、画面确认及交付流程仍可通过旧历史项目访问。示例文案不属于已审核医学文稿，导出的 HTML 未验证微信公众号编辑器或发布兼容性。

素材库支持导入、替换、移除本地图片和视频。图片支持 PNG、JPG、WEBP、GIF；视频支持 MP4、WEBM、MOV，能否播放取决于浏览器编码支持，建议使用 H.264 MP4。素材库单文件上限 200 MB，会检查媒体是否可解码。移除素材不会删除电脑原文件。

## 数据与验证

手动导入的素材和视频会话参考文件保存在浏览器 IndexedDB，项目导航历史、文献编辑内容及部分界面状态保存在 localStorage。刷新可恢复已保存的本地内容；清除网站数据会删除这些记录。数据按协议、主机、端口和浏览器隔离，`localhost` 与 `127.0.0.1` 不共享；建议固定使用 http://127.0.0.1:5173。项目没有登录或云同步功能，请保留原始素材并导出所需文稿。

新版文献流程将最近一次提交及图片保存在 IndexedDB，逐段编辑按独立任务 ID 保存在 localStorage；刷新仍进入新建页面，点击“继续上次文稿”恢复。旧版本编辑数据保留。未提交的上传草稿及被取消的加载不作为已完成结果保存。

新版图文将每个作品的正文、图片和编辑内容按任务 ID 保存在 IndexedDB，localStorage 仅保存历史导航摘要。结果页刷新恢复当前作品，新建页可继续上次作品；保存失败时会显示重试入口。未提交的输入不会在刷新后恢复。

```bash
npm run verify:literature
```

现有验证脚本覆盖文献数据、引用关联、自定义输入隔离及兼容保留的旧状态逻辑；它不替代新版编辑器、导出下载、视频多轮对话和浏览器恢复的交互验证。
