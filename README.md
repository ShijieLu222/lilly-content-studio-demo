# Lilly Content Studio Demo · 礼来创意工作台

面向礼来项目招标展示的本地 React Demo。它把“生成式长图文”“生成式视频”和“文献溯源”放在统一的 LLM 平台式工作台中，以已准备的成品和证据关联结果展示价值，以可操作的 Agent 工作流解释过程。图文保留 **5 张系列海报**的位置；视频已随项目接入 **同一场大会的 2 个开场动画版本**，打开即可演示，无需再次导入。文献页采用核心 POC 文件中的宁博士 13 段脚本和三张 H5 原图，以预置改写和证据映射演示，不依赖在线模型或后端服务。

## 产品与演示设计

左侧保留四个主要跳转入口：**工作台、图文创作、视频创作、文献支持**。主工作台负责介绍和进入三个产品，素材库与品牌设置移至顶部工具区，不再占用主要导航。三个产品共用礼来品牌界面，但保留各自的工作流：图文侧重视觉叙事与系列一致性，视频侧重镜头与节奏，文献侧重每段主张与证据之间的对应关系。

图文产品支持五张海报逐张预览，并将这五张成品编排为连续阅读的长图文预览。该编排使用演示标题、章节和说明文字，不代表已经生成一篇经过医学审核的文章，也不额外要求第六张长图素材。

视频产品围绕「领峰者之夜」暨穆峰达®全球重磅研究中国发布盛典的两版开场动画展开。两个 MP4 均为用户提供的原文件副本，画面、声音与时长完整保留；没有剪辑、重新编码或在线生成。界面以实际成片整理创意方向、代表帧和分镜，并提供双版本播放、对比、画面定位和下载。

| 版本 | 创意方向           | 原片规格                           | 内容与对应文件                                                                                 |
| ---- | ------------------ | ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| A    | 光束转场，主题揭幕 | 约 5.033 秒 · 1920 × 1080 · 30 fps | 讲者题卡 → 光束展开 → 主题揭幕 → 英文披露页；原文件 `47ef63d8-c3aa-4717-bb02-fa6b601710a5.mp4` |
| B    | 星光汇聚，盛典启幕 | 约 6.083 秒 · 1280 × 720 · 24 fps  | 星空蓄势 → 光束汇聚 → 标题渐显 → 主视觉落版；原文件 `45d17732225fa07ce494c296407c6b6c.mp4`     |

原片分别保存在 `public/assets/videos/conference-opening-a.mp4` 与 `conference-opening-b.mp4`。每版有四张对应时刻的原片代表帧；点击结果预览中的分镜卡可定位到截图时刻。时间段用于解释叙事节奏，连续渐变部分不代表逐帧剪辑点。A 版的讲者题卡与英文披露页属于原始内容，演示中保留并列入现场播放顺序的复核项。

图文与视频工作区使用紧凑工具栏与横向七阶段进度条，创作对话和成果预览分别滚动。原始需求可以展开查看，底部输入栏聚焦后增加编辑空间。图文创意卡片放大文字，成果区保留海报比例与长图滚动；视频交付后的版本切换采用缩略图卡片，主播放器完整保留 16:9 比例。

图文与视频的右侧最终成果区只在完整流程结束后开放：项目必须处于成果交付阶段、七个阶段全部完成，且本轮已确认的素材与当前文件版本一致。在此之前，右侧显示流程进度与等待提示，不提前开放最终预览、视频对比、成果下载或专注预览。创意卡与分镜图仍作为流程中的参考资料展示。素材库保留后台素材管理入口，方便演示前接入或替换文件。

文献支持对应核心文件的两项任务：达人脚本表达优化与 H5 文献支持。页面保留原始内容，演示主张拆解、证据关联、建议表达、修改理由和待核查项；结果不代表正式医学审批。

视觉以礼来红和柔和粉色为主、浅紫为辅助，参考提供的现有平台截图。左上角采用 [礼来官网](https://www.lilly.com/) 提供的原版红色 SVG Logo，已去掉品牌名称后的 AI 字样，素材本地保存。当前 Demo 配色不是完整的官方品牌手册，正式字体与审批信息仍需由项目方提供。

## 本地启动

在本项目目录打开终端，执行：

```bash
npm install
npm run dev
```

打开 **http://127.0.0.1:5173**。开发服务器只监听本机地址，端口固定为 5173；如果端口已被占用，先关闭占用该端口的程序再启动。首次安装依赖需要网络，应用运行与素材预览不调用外部生成服务。

需要构建时执行：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`，预览地址以终端输出为准。生产预览可能使用不同端口，因此不会自动显示开发地址下保存的浏览器数据。

## 建议演示顺序

1. 视频的两版成片已就位。图文演示前，从顶部素材库接入五张海报，可批量导入或按主题逐个选择；批量导入按选择顺序填入空位，不覆盖已有文件。
2. 从工作台进入视频创作，查看大会任务与成片依据，在两个创意方向中选择版本 A 或 B 并确认。
3. 查看所选版本的四段分镜，确认后进入制作流程动画。此时右侧仍等待流程完成；可查看工作流全貌与决策记录。
4. 在“确认交付准备”阶段核对本轮版本及素材就绪状态，点击“完成流程，展示成果”。七个阶段全部完成后，右侧才出现真实成片，并开放专注预览、下载与版本对比。切换另一版仅用于对比，不改变本轮确认对象；按展示后检查清单复核标题、节奏、声音与起止画面。
5. 点击交付页的“演示版本 A／B 完整流程”，为另一版本新建项目，再走一次创意、分镜与交付准备确认。新项目的最终成果会重新隐藏，两版分别保存项目与决定，先前记录仍可从最近创作中打开。
6. 图文创作按照同样的七阶段流程选择概念、确认画面并完成交付准备，流程结束后再展示五张海报、长图文编排与下载入口。提出修改或重新演示时，最终成果再次隐藏，直至新一轮流程完成。
7. 切换文献溯源，用固定案例展示“段落 → 主张 → 文献 → 支持范围”；再展示部分支持与证据缺口，说明系统如何处理无法直接引用的表述。

这是“结果先行”的演示策略：先准备有说服力的作品，再用阶段产物、决策与修改回路解释 Agent 如何协助创作。页面中的制作进度是预设流程动画，不是实时生成耗时。

## 图文与视频的七阶段和三个确认点

| 阶段              | 主要呈现                             | 推进方式         |
| ----------------- | ------------------------------------ | ---------------- |
| 1. 需求解析       | 传播任务与固定要求示例               | 自动推进         |
| 2. 参考检索       | 项目资料与创作依据示例               | 自动推进         |
| 3. 创意概念       | 图文三种方向；视频 A／B 两版方向     | 用户选择并确认   |
| 4. 画面／分镜方案 | 图文构图草图；视频所选版本的四段分镜 | 用户确认方案     |
| 5. 制作合成       | 制作流程动画与素材装配               | 自动推进         |
| 6. 交付确认       | 交付对象、素材状态与展示后检查清单   | 用户确认准备就绪 |
| 7. 成果交付       | 最终成果、完整预览与下载             | 完成本地演示     |

自动推进会在创意、方案和交付准备三个确认点停下。交付准备确认表示本轮方案与素材就绪，并不表示已经查看或正式审核最终画面；完整成果在流程结束后展示，随后按清单复核。回到创意阶段会使后续方案与交付确认失效；调整画面保留创意；局部修改保留上游决定。重新演示或退回修改会收起最终预览、视频对比、成果下载与专注预览，直至流程再次完成。输入修改意见只会记录要求并更新流程，不会自动修改图片或视频；修改后需要接入修改后的成品，再进行确认。

交付确认记录关联素材版本。已完成项目所用的素材被替换、删除或恢复原版后，会重新进入交付确认状态并隐藏最终成果。视频只确认本轮选择的版本，切换对比预览不改变确认对象，另一版素材变动也不会使本版确认失效。素材库由项目共享，替换同一位置的文件会影响引用该位置的历史项目。

## 脚本优化与文献支持

核心来源为 `AI Content Creation - POC Files - 20261023.docx`，当前实现两个固定本地案例：

- **达人脚本**：第二个内嵌 Word 的宁博士 13 段口播表，保留原始编号、时长、画面、花字和逐字口播。标题备选、发布文案不混入固定输入。原始 Word 可在页面下载。
- **H5 文献支持**：正文三张 H5 原图，保留原图顺序、文字区域、上标引用编号和共用文末书目。点击图上区域可查看对应原文及结果。

固定脚本的文献已于 **2026-10-27 实际联网检索并核对**：11 条来源（9 项原始研究、2 份官方文件），对应第 2–12 段的 28 条具体主张关联。收录的研究包括 Sacks 2009、Leibel 1995、Fothergill 2016、Sumithran 2011、Villareal 2017、Longland 2016、Nedeltcheva 2010、Tasali 2022 及 Peppard 2000。每条文献标明实际核对层级（全文相关段落／摘要／官方文件）、位置、日期、适用范围及 DOI/PMID。部分来源正文访问受限，仅标摘要核对；没有用预设链接冒充完成全文核验。

两份卫健委官方 PDF 随项目保存到 `public/literature/references/`，文献卡可直接定位对应 PDF 页面。参考文献视图保留真实检索词，可下载 RIS；`ning-research-record.json` 保存可追溯的来源和映射。第 1 段开场提问无需强配文献；第 13 段未定义的效果承诺仍保留待核查。旧版完成状态会因证据版本更新而失效，需重新演示。

流程为 **确认输入 → 拆解主张 → 文献匹配 → 表达优化 → 结果复核 → 报告交付**。先确认原文，再确认主张，演示依次载入预置文献和表达建议，停在结果复核。点击“完成流程，查看报告”后才显示最终成果与导出。

文献页的双栏内容区占满桌面剩余高度。未交付时，右侧锁定提示、说明与进度作为整体在成果面板内居中，并按可用空间调整尺寸。

右侧结果包含逐段对照、完整建议稿、参考文献和过程记录。每段保留原文、建议表达、修改理由、主张、支持位置和适用边界。状态分为“有对应依据”“部分支持”“待核查”“无需引用”。参考文献同时注明书目核对范围；未完成核查的 H5 原图引用继续明确标记待核查，不补造 DOI 或原文入口。

**状态与重演**：重新演示、编辑原文、切换案例会立即收起报告和导出。旧定时器不能恢复上一轮结果。处理期间刷新会回到主张确认，须重新继续；已经完成的有效版本可以恢复。案例数据版本变化会使旧完成状态失效。

自定义文字、TXT 或图片人工转录可以演示输入与整理过程；只有完整匹配固定版本的原文才读取对应预置证据。自定义输入最终仍为待核查，不自动套用示例引用或改写。图片未连接 OCR；导入图片本体只在当前会话保留，内置 H5 原图随项目保存。

本地流程不实时访问 PubMed、检索全网或调用大模型。文献链接用于打开外部一手来源，需要联网；所有预置段落、图像、流程和结果展示可离线通过本地服务运行。JSON 和 Markdown 导出包含完整建议稿、逐段原文与依据、引用和过程记录。

验证命令：`npm run verify:literature`，覆盖完成门槛、重置、旧定时器、案例切换、刷新恢复、自定义输入隔离，以及文献与图像区域关联。

## 成品接入与导出

五张海报位置依次对应一站式服务、前沿资讯、文献查询、临床研究、用药指南。支持 PNG、JPG、WEBP、GIF；视频支持 MP4、WEBM、MOV，能否播放取决于浏览器支持的编码。单文件上限为 200 MB，建议视频使用 H.264 MP4。导入会检查文件是否能被浏览器解码，错误会在素材库中提示。

视频的 A、B 两个位置默认读取随项目提供的本地原片。手动“替换视频”后，当前浏览器中的替换文件优先展示；点击“恢复原版”会移除该位置的浏览器覆盖文件，重新使用项目中的原始 MP4。操作不会改写项目原片或电脑上的源文件。替换成片的时长与分辨率由播放器读取；结果区不再将原片截帧当作替换文件的分镜，创意流程中的原版参考也会明确提示需要重新核对。

- **原始成品下载**：完整流程结束后，保存当前预览的图片或视频文件。视频对比时下载的是正在预览的版本；本轮流程确认对象仍以“当前流程选择”为准。
- **长图文编排导出**：完整流程结束后，在“长图文编排”模式下载独立 HTML，图片嵌入文件，可离线打开。它是浏览器编排预览，未验证公众号编辑器、SVG 或发布后的兼容性。
- **图文／视频项目 JSON 导出**：包含需求、阶段、选择、修改记录、素材清单和项目约束；视频另记录本轮选中版本、素材来源及分镜参考。不包含媒体文件本体。用于留档和复盘，当前未实现 JSON 导入恢复。
- **文献结果导出**：支持 JSON 与 Markdown，保存原文、建议表达、修改理由、逐段主张、文献关联及证据边界。当前不支持结果 JSON 导入。

未接入图文素材时仍可浏览流程与示意版式；图文交付准备确认需要五张海报就位。视频交付准备确认要求本轮所选版本的文件可用，默认两版均随项目提供。图文、视频最终成果均在七阶段全部完成且当前素材仍符合确认记录后展示。示意画面有明确标注，不作为真实生成结果交付。

## 本地数据说明

手动导入的图片与替换视频保存在浏览器 **IndexedDB**；两版默认视频及其代表帧保存在项目的 `public/assets/videos/` 中，运行时从本地服务读取。项目历史、进度和品牌约束保存在 **localStorage**。浏览器数据绑定当前配置及网址来源（协议、主机、端口），`localhost` 与 `127.0.0.1`、不同端口、不同浏览器之间不会自动共享。

文献页使用独立的 v2 localStorage 记录输入、阶段、确认版本和过程。预置证据由源文件读取，不从旧会话恢复过期映射。用户上传的图片本体只在当前页面会话中保留；内置三张 H5 原图永久随项目保存。

建议始终使用 `http://127.0.0.1:5173` 演示。清除网站数据、使用另一浏览器或更换地址后，手动导入的海报与替换视频可能需要重新导入，项目流程记录也不会自动迁移；随项目提供的两版视频仍会默认载入。请保留电脑上的原始成品并导出项目记录。从素材库移除文件不会删除电脑里的原文件。项目没有登录、云同步或服务器上传功能。
